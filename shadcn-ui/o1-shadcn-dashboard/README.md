# 🧩 Shadcn Dashboard Demo ✨🚀

[![Vista del proyecto](./docs/web.png)](http://localhost:3000)

Un dashboard de práctica construido con **Next.js 16**, **React 19**, **TypeScript** y **Tailwind CSS**, enfocado en mostrar componentes modernos de `shadcn/ui` + Radix en un entorno realista. Ideal para aprender, reutilizar UI patterns y acelerar prototipos frontend. 🎯📦

## Quick start ⚡️
Instala y ejecútalo localmente:

```bash
# clone (if needed)
git clone https://github.com/elliotgaramendi/devtalles.git
cd shadcn-ui/o1-shadcn-dashboard

# instalar dependencias
npm install

# iniciar entorno de desarrollo
npm run dev

# compilar para producción
npm run build

# ejecutar build de producción
npm run start

# correr linter
npm run lint
```

Abre: [http://localhost:3000](http://localhost:3000)

## Functionalities ✨🎯🔥
- 🧭 Estructura tipo dashboard en `/dashboard` con navegación por vistas.
- 🧩 Showcase de componentes UI listos para usar y personalizar.
- 📋 Data table con ejemplo de columnas y datos.
- 📝 Formularios con validación y controles interactivos.
- 🌗 Soporte de tema claro/oscuro (`next-themes`).
- 🎞️ Componentes avanzados: `carousel`, `dialog`, `sheet`, `tabs`, `alert-dialog`, `sonner` y más.
- 🎨 Estilos utilitarios con Tailwind CSS 4.
- ⚙️ Base limpia para aprendizaje, demos técnicas o nuevas features.
