# 🧪 [API Test App](https://github.com/elliotgaramendi/devtalles/tree/develop/react-native-expo/o11-api-test)

A modern **API testing playground** built with **React Native** and **Expo**. Switch between multiple public APIs, visualize real-time responses, handle loading and errors, and explore data using a clean and developer-friendly UI. 🚀📡

---

## ✨ Features

* 🔌 Real-time API connectivity testing
* 🔄 Switch between multiple APIs instantly
* 🧠 Smart data fetching with TanStack Query
* ⚡ Automatic caching & refetching
* 🚨 Error handling with retry support
* 📊 Response stats (status, records, state)
* 🧾 JSON response viewer
* 🎨 Modern dark UI with rich feedback
* 📱 Android & iOS support

## 🚀 Getting Started

1. **Clone the repository**

```bash
git clone https://github.com/elliotgaramendi/devtalles
cd react-native-expo/o11-api-test
```

2. **Install dependencies**

```bash
npm install
```

3. **Start the development server**

```bash
npx expo start
```

4. **Run the app**

* 📱 Scan QR with **Expo Go**
* 🍏 Press `i` for iOS simulator
* 🤖 Press `a` for Android emulator
