# TypeScript Foundations

Proyecto de práctica con TypeScript y Vite. Incluye ejemplos sencillos de tipos, interfaces, clases, peticiones HTTP, inyección de dependencias y decoradores.

## Tecnologías

- TypeScript
- Vite
- Axios y Fetch API
- PokéAPI

## Ejecutar localmente

```bash
pnpm install
pnpm dev
```

Para crear una versión de producción:

```bash
pnpm build
```

Los ejemplos principales están en [`src/ts`](./src/ts).
