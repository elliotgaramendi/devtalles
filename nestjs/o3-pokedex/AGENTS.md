# Project conventions

- Use `nest-o3` as the Conventional Commit scope for every change in this project. The `o3` identifier refers to this project's position in the NestJS learning series, so do not use `o3-pokedex` as the scope.
- Use `pnpm` for dependency management and project scripts.
- Separate external imports from local imports with one blank line.
- Keep static HTML and CSS in separate files under `public/`.
- Before committing, run ESLint, the relevant tests, and the production build.
